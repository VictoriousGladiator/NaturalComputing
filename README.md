# NaturalComputing

You will design, implement, and analyze your own cellular Potts modeling experiment to investigate the impact of obstacles on
collective migration, and submit your findings in a small report. At this stage, you are submitting a draft that
will not yet be graded – you will first receive feedback and get a chance to revise your work before the final
submission.

## Running the HTML simulations

The HTML simulations in `A1/simulations/` expect the Artistoo build to be present at `A1/artistoo_minimal/` (they load `../artistoo_minimal/build/artistoo.js`). Make sure you include/copy the `artistoo_minimal` folder inside `A1/` before opening the simulation `.html` files.
